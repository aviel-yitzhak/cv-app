# Interactive Resume Builder - v1.0

A professional React-based application designed to create interactive resumes with real-time preview and PDF export optimization.

## 🚀 Development Milestones
- **Phase 1:** Infrastructure setup using React + Vite.
- **Phase 2:** Integration of Tailwind CSS for a modern, responsive UI.
- **Phase 3:** Real-time state management for instant content updates.
- **Phase 4:** Print optimization for precise A4 PDF export.
- **Phase 5:** Deployment to GitHub Pages.

## 🛠 Technologies Used
- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Build Tool:** Vite
- **Deployment:** GitHub Pages

## 📖 How to Use
1. Edit your details in the sidebar.
2. View changes instantly in the preview pane.
3. Click "Download PDF" to save your resume (Ensure "Background Graphics" is enabled in print settings).
