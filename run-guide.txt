# מדריך הרצה - פרוייקט CV

## 🖥️ להריץ לוקלית (במחשב שלך)

פתח טרמינל בתיקיית הפרוייקט והרץ:

```bash
npm run dev
```

זה יפתח את האתר ב: http://localhost:5173/cv-app/

**לעצור את השרת:** לחץ `Ctrl + C` בטרמינל

---

## ✏️ לערוך את הקורות חיים שלך

**כל העריכות שלך צריכות להיות ב:**
```
src/resumeData.js
```

פשוט תפתח את הקובץ הזה ותערוך את הפרטים שלך.

**הקובץ הזה לא יעלה לגיטהאב** - הוא רק במחשב שלך.

---

## 📤 לעדכן שינויים בקוד (לא בקורות חיים)

**אם שינית משהו ב-App.jsx, עיצוב, או קוד:**

### שלב 1: בדוק מה השתנה
```bash
git status
```

### שלב 2: הוסף את השינויים
```bash
git add .
```

### שלב 3: צור commit
```bash
git commit -m "תיאור השינוי שעשית"
```

### שלב 4: העלה לגיטהאב
```bash
git push origin main
```

### שלב 5: עדכן את האתר
```bash
npm run build
npm run deploy
```

חכה 2-3 דקות והאתר יתעדכן ב: https://aviel-yitzhak.github.io/cv-app/

---

## 🌐 רק לעדכן את האתר (בלי שינויים בקוד)

אם רק רצית לרענן את האתר:

```bash
npm run build
npm run deploy
```

---

## 💡 איך זה עובד?

**יש לך 2 קבצי נתונים:**

1. **`src/resumeData.js`** - הפרטים האישיים שלך
   - נמצא רק במחשב שלך
   - לא יעלה לגיטהאב (הוא ב-gitignore)
   - משמש כשאתה מריץ `npm run dev`

2. **`src/resumeData.example.js`** - תבנית גנרית
   - נמצא בגיטהאב
   - משמש כשעושים `npm run build` (production)
   - זה מה שאנשים רואים באתר הציבורי

**בזכות זה:**
- אתה עובד על הקורות חיים שלך במחשב
- האתר הציבורי מציג תבנית גנרית
- לא צריך לשנות שום דבר ידנית!

## ❓ פקודות שימושיות

```bash
# לראות את כל ה-commits
git log --oneline

# לראות את ההבדלים בקובץ
git diff <שם-קובץ>

# לבטל שינויים (לפני commit)
git restore <שם-קובץ>

# לבטל commit אחרון
git reset --soft HEAD~1

# לראות את כתובת הגיטהאב
git remote -v
```

## 🔄 זרימת עבודה רגילה

**לעדכן את הקורות חיים שלך:**
1. ערוך `src/resumeData.js`
2. `npm run dev` - תראה את השינויים
3. זהו! (אין צורך ב-git)

**לשנות משהו בקוד:**
1. ערוך את הקבצים
2. `git add .`
3. `git commit -m "תיאור"`
4. `git push origin main`
5. `npm run build`
6. `npm run deploy`
